# Artisan Roots - Handicraft & Clothing Store

A static, single-page application (SPA) e-commerce website for a handicraft and clothing boutique.

## Features
- Fully responsive, mobile-first design.
- Direct WhatsApp order integration (no backend required).
- Product filtering by category.
- Custom order request form.

## Technologies Used
- HTML5
- CSS3 (Custom Properties/Variables, Flexbox, Grid)
- Vanilla JavaScript
- Google Fonts (Playfair Display, Poppins)

## Setup & Deployment
1. No build step is required.
2. Edit `products.js` to add or modify products.
3. Update `SHOP_PHONE` in `script.js` to the shop owner's WhatsApp number (country code + number, no '+' or spaces).
4. Deploy the folder to any static hosting service like GitHub Pages, Netlify, or Vercel.

## File Structure
- `index.html`: The main website markup.
- `style.css`: Styling and responsive layout.
- `script.js`: Handles logic for product rendering, filtering, modals, and WhatsApp message formatting.
- `products.js`: A JavaScript array acting as the product database.
